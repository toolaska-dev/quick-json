# Contributing to Toolaska Quick-JSON

Thank you for your interest in contributing to **Quick-JSON**! 

Quick-JSON is a free online tool hosted at **[https://json.toolaska.com](https://json.toolaska.com/)** designed to help developers format, validate, beautify, and inspect JSON structures efficiently.

---

## 🧭 Ways to Contribute

1. **Bug Reports**: Open an issue describing unexpected behavior, syntax parser edge cases, or rendering bugs.
2. **Feature Suggestions**: Propose new utilities (e.g., additional export formats, schema generators, query helpers).
3. **Documentation & SEO**: Improve guides, fix typos, or suggest SEO and schema enhancements.
4. **Pull Requests**: Submit code improvements or optimizations.

---

## 🛠️ Contribution Workflow

1. **Fork the Repository**:
   Click the **Fork** button at the top right of this repository.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/quick-json.git
   cd quick-json
   ```

3. **Create a Topic Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Your Changes**:
   - Ensure code is clean, readable, and well-documented.
   - Maintain strict client-side data privacy (never transmit user JSON payloads to external services).

5. **Commit with Clear Messages**:
   ```bash
   git commit -m "feat: add schema validation shortcut"
   ```

6. **Push and Open a Pull Request**:
   Push to your branch and submit a PR to `main` against `toolaska-dev/quick-json`.

---

## 📋 Code of Conduct

Please treat all community members with respect, kindness, and professionalism. We are committed to providing a welcoming and inclusive environment for everyone.
