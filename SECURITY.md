# Security & Privacy Policy

## 🔒 Client-Side Privacy Guarantee

The core design principle of **Toolaska Quick-JSON** ([https://json.toolaska.com](https://json.toolaska.com/)) is zero data retention:

- **100% In-Browser Execution**: All formatting, validation, beautification, and minification runs entirely within the client's web browser using client-side JavaScript APIs.
- **Zero Server Uploads**: No user-entered JSON strings, keys, values, or uploaded files are sent over the network to any server.
- **Zero Database Storage**: We do not store, log, or persist user payloads in any database.

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability or potential privacy concern in Toolaska Quick-JSON, please report it responsibly so we can address it promptly.

### How to Report:
- **Email**: Send vulnerability reports directly to `info@toolaska.com`.
- Please do **not** open public GitHub issues for sensitive security vulnerabilities.

### What to Include:
- A clear description of the vulnerability.
- Steps to reproduce or proof of concept.
- Affected browser versions or operating systems.

We take security seriously and appreciate the developer community's efforts in keeping our tools safe.
